# Chrome-extension Specification

> Generated by spec-gen v1.0.0 on 2026-03-14 21:32

## Purpose

Orchestrates the export of DOM trees with XPath annotations. Manages the complete lifecycle of DOM
element extraction, indexing, and tree reconstruction.

## Requirements

### Requirement: Exportdomtreewithxpath

The system SHALL main entry point that coordinates dom tree export with xpath generation. initializes index, collects dom elements, builds tree structure, and computes statistics.

#### Scenario: ExportFromDefaultDocumentBody
- **GIVEN** No rootElement provided
- **WHEN** exportDOMTreeWithXPath is called
- **THEN** Uses document.body as root, builds index, exports full DOM tree

#### Scenario: ExportFromSpecificElement
- **GIVEN** rootElement parameter provided
- **WHEN** exportDOMTreeWithXPath is called
- **THEN** Uses provided element as root, builds index from subtree, exports limited DOM tree

### Requirement: Getdomtreeasync

The system SHALL asynchronously collects dom elements from document, processes each element to extract content, attributes, and generate ids, then builds hierarchical tree structure.

#### Scenario: SuccessfulTreeConstruction
- **GIVEN** Valid rootElement with child elements
- **WHEN** getDOMTreeAsync is called
- **THEN** Returns nested tree structure with each node containing element data

### Requirement: Getstats

The system SHALL returns statistics about the exported dom tree including element counts by type.

The system SHALL generates a stable xpath for a given element by computing the optimal path using index and uniqueness checks.

#### Scenario: GenerateXpathForUniqueElement
- **GIVEN** Element with unique ID
- **WHEN** generateXPath is called
- **THEN** Returns short XPath using ID attribute

#### Scenario: GenerateXpathForNonUniqueElement
- **GIVEN** Element without unique ID
- **WHEN** generateXPath is called
- **THEN** Returns longer XPath with position or class constraints

### Requirement: Computexpath

The system SHALL core computation logic for xpath generation. evaluates element uniqueness, handles dynamic ids, checks for blacklisted classes, and builds relative path.

#### Scenario: ComputeWithIframeContext

- **THEN** Generates iframe-aware XPath including iframe path
